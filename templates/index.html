Honey Token Honeypot

Catch attackers who steal API keys from exposed .env files

Home Dashboard

Step 1: Attacker Discovers the .env File

The attacker finds the exposed configuration file at:

GET http://localhost:5000/.env

This returns fake but realistic-looking API keys:

STRIPE_API_KEY=sk_live_abc123...
AWS_ACCESS_KEY=AKIA...
GITHUB_TOKEN=ghp_...

Step 2: Attacker Uses the Stolen Keys

The attacker tries to use a stolen key to access your API:

curl -X POST http://localhost:5000/api/v1/payments \
  -H "Authorization: Bearer sk_live_abc123..."

Step 3: Alert is Triggered

When the attacker uses ANY stolen key, the system:

  • ✓ Logs their IP address
  • ✓ Records their location (city/country/ISP)
  • ✓ Notes which API they tried to access
  • ✓ Shows alert on dashboard instantly

Simulate an Attack

From another device or terminal:

# First, steal the .env file
curl http://[YOUR_SERVER_IP]:5000/.env

# Copy any key from above, then use it:
curl -X POST http://[YOUR_SERVER_IP]:5000/api/v1/payments \
  -H "Authorization: Bearer [PASTE_STOLEN_KEY]"

# Or try the AWS endpoint:
curl "http://[YOUR_SERVER_IP]:5000/api/v1/aws/s3?key=[STOLEN_KEY]"

Watch the dashboard refresh with the attacker's information!
