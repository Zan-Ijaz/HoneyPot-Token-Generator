Log telemetry formats

The platform automatically exports all threat triggers to instance/siem.log. For compatibility with platforms like Splunk, Elastic, and QRadar, logs are written in both Common Event Format (CEF) and JSON structures.

Example CEF Log Structure:
CEF:0|HoneyTokenSys|API_Generator|2.0|AWS_TRIGGERED|Honeytoken Trigger Event|8|src=192.168.1.105 request=/api/v1/aws/s3 msg=Honeytoken compromised: AWS S3 Production cs1Label=AttackerProfile cs1=Scripted exploit / CLI tool cs2Label=AIExplanation cs2=Multi-step credential validation probes detected. cn1Label=RiskLevel cn1=HIGH deviceCustomDate1=2026-06-03T23:05:00
Example JSON Log Structure:
{
  "event": "honeytoken_trigger",
  "timestamp": "2026-06-03T23:05:00",
  "token_id": "AWS_001",
  "src_ip": "192.168.1.105",
  "location": "Localhost (Demo)",
  "risk_level": "HIGH",
  "profile": "Scripted exploit / CLI tool",
  "prediction": "Multi-step credential validation probes detected."
}
